yolov9_t.onnx

A YOLOv9-T object detector, trained on the COCO dataset (80 classes).

Source of the model and its weights:
  MultimediaTechLab/YOLO, https://github.com/MultimediaTechLab/YOLO
  Release v1.0-alpha, file v9-t.pt. MIT License.
  Copyright (c) 2024 Kin-Yiu Wong and Hao-Tang Tsui

Converted by:
  LibreYOLO, https://huggingface.co/LibreYOLO/LibreYOLO9t
  File LibreYOLO9t.onnx, MIT License. Its model card says the conversion
  renamed the weight keys only and left the learned values unchanged.
  The file here is that file under another name, unchanged:
  8,451,972 bytes, SHA-256
  6956ca35e4429f92609b68e2599df2ebb2dd0ccecb526341b1268f84d96eb527

Not used: the first YOLOv9 code, WongKinYiu/yolov9, which is under GPL-3.0.
Nothing in this project comes from it.

The class names this model reports are in coco_classes.txt.
