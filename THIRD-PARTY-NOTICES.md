## 1. Detection model

**`Assets/Models/yolov9_t.onnx`**: YOLOv9-T, trained on COCO (80 classes).
- Source: MultimediaTechLab/YOLO, https://github.com/MultimediaTechLab/YOLO, release v1.0-alpha, file
  `v9-t.pt`.
- Converted to ONNX by LibreYOLO, https://huggingface.co/LibreYOLO/LibreYOLO9t, file `LibreYOLO9t.onnx`.
  The model card says the conversion only renamed the weight keys and left the learned values unchanged. The
  file here is that file under another name, unchanged: 8,451,972 bytes, SHA-256
  `6956ca35e4429f92609b68e2599df2ebb2dd0ccecb526341b1268f84d96eb527`.
- Licence: MIT, Copyright (c) 2024 Kin-Yiu Wong and Hao-Tang Tsui (text A). The same notice is beside the file
  in `Assets/Models/YOLOV9-T-NOTICE.txt`.
- Not used: the first YOLOv9 code, https://github.com/WongKinYiu/yolov9, which is under GPL-3.0. Nothing in
  this repository comes from it.

**`Assets/Models/coco_classes.txt`**: COCO's 80 class names, in the same order as stored in the model file.
This text copy was first taken from YOLOX, `yolox/data/datasets/coco_classes.py`,
https://github.com/Megvii-BaseDetection/YOLOX. Licence: Apache-2.0, Copyright (c) 2021-2022 Megvii Inc.
(text B). The display names in `Assets/Models/coco_display_names.txt` are this project's own.

**Sketchfab, CC BY 4.0 (text D).** Notice file: `Assets/Models/Props/SKETCHFAB-NOTICE.txt`.

- `Assets/Models/Props/monitor_dell_p2314h/monitor.fbx` is based on "Monitor Dell P2314H"
  (https://sketchfab.com/3d-models/monitor-dell-p2314h-c69f09bb812e46cdbd5bf6c62499b848) by GregorJan
  (https://sketchfab.com/login166), licensed under CC BY 4.0. Changes: turned from glTF into FBX; its small
  parts joined into one mesh with three materials; scaled to real size (54 cm wide). The picture on its screen
  was replaced by a plain desktop picture made for this project (`monitor_screen.png`).
- `Assets/Models/Props/mouse_and_keyboard/keyboard.fbx` and `mouse.fbx` are based on "Mouse and Keyboard"
  (https://sketchfab.com/3d-models/mouse-and-keyboard-c63ee81b71ff45b68a778101b4df3d46) by gorzi
  (https://sketchfab.com/gorzi90), licensed under CC BY 4.0. Changes: turned from glTF into FBX and split into
  two files; materials merged; scaled to real size (keyboard 44 cm long); faces reduced from 131,360 to 21,605
  (keyboard) and from 32,628 to 5,944 (mouse); two small loose parts left out. `keyboard_keys.png` is the
  model's own key texture.

Everything else in the test room (walls, desks, tables, cabinet, door, whiteboard, bin, light panels) is built
from Unity's own shapes for this project, with this project's materials in `Assets/Environments/Materials/`.
